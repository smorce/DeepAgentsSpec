# Feature Specification: F-SYS-012 状態管理・永続化・差し替え表現

## Overview

エージェント実装で重要な「いつ・何を・どこへ退避し、会話側を何に置換するか」をSoRとして固定する。

## Functional Requirements

- FR-012-001: ホット状態（最新）をJSONで保持する。
- FR-012-002: コールド状態（履歴）をJSONLで追記退避できる構造にする。
- FR-012-003: 会話側で利用する差し替え表現テンプレートを定義する。
- FR-012-004: 状態スキーマを `runtime_state_schema.json` に固定する。

## Non-Functional Requirements

- NFR-012-001: 個人情報やシークレットを状態ファイルへ保存しない。
- NFR-012-002: スナップショットは再現可能な最小情報のみ持つ。

## Success Criteria

- SC-012-001: 状態スキーマが存在し、必須フィールドが定義される。
- SC-012-002: 差し替え表現がドキュメント化され、手順から参照できる。
